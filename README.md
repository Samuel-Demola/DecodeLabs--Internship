# DecodeLabs Data Analytics Internship 2026

Data Analytics internship repository for the DecodeLabs 
2026 batch — documenting project work across data cleaning, 
exploratory analysis, SQL querying and dashboard visualization 
using Excel, SQL Server and Power BI.

## Projects

### Project 1 — Data Cleaning & Preparation
- Cleaned 1,200 row sales dataset
- Handled 309 missing values, fixed floating point errors
- Documented all changes in a structured change log

### Project 2 — Exploratory Data Analysis
- Descriptive statistics across all numeric columns
- Outlier detection using IQR method (8 outliers found)
- Correlation analysis, pivot tables and trend charts
- Key finding: 41.4% cancel/return rate flagged as critical

### Project 3 — SQL Data Analysis
- 15 SQL queries written in SQL Server Management Studio
- Covered WHERE, GROUP BY, ORDER BY, HAVING, AGGREGATION, COUPON Analysis
- Extracted insights on revenue, order status and customer behaviour

### Project 4 — Power BI Dashboard
- Interactive sales dashboard built in Power BI Desktop
- Visuals: KPI cards, line chart, donut chart, bar charts
- DAX measures for dynamic calculations
- Navy, Teal and Amber professional color theme
